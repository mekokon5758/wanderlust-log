# Wanderlust Log

**Wanderlust Log** is a full-stack travel journal web application built with Django. Users can create and manage reviews of countries they have visited, rate their experiences, and view their travel history through a personalized profile.

### Features

* Create and manage country reviews
* View visited countries and individual reviews
* User profiles with profile images and biographies
* Responsive web interface

### Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, Bootstrap
* **Database:** SQLite
* **Version Control:** Git / GitHub
